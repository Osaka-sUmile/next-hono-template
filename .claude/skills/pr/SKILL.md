# /pr

プルリクエスト作成スキル。ブランチの変更を分析し、適切なPRを作成する。

## 使用方法

```
/pr [ベースブランチ]
```

デフォルトのベースブランチは `dev`

## 処理フロー

1. 現在のブランチ状態を確認
2. ベースブランチとの差分を分析（全コミットを確認）
3. PRタイトルとサマリーを生成
4. 必要に応じてリモートにプッシュ
5. `gh pr create` でPRを作成

## PRテンプレート

```markdown
## Summary
<1-3行の箇条書き>

## Test plan
- [ ] 単体テストの実行
- [ ] 統合テストの実行
- [ ] 手動テストの実行

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

## PRタイトル規約

- 70文字以内
- 変更内容を簡潔に表現
- 形式: `[FE]` / `[BE]` / `[共通]` プレフィックス推奨

### 例
```
[FE] ユーザー認証フローの実装
[BE] 組織管理APIの追加
[共通] Date型変換ロジックの統一
```

## コマンド例

```bash
# 基本的な使用
/pr

# ベースブランチを指定
/pr main

# PRの詳細を確認
gh pr view
```

## 注意事項

- PRを作成する前に、すべての変更がコミットされていることを確認
- リモートにプッシュされていない場合は自動的にプッシュ
- PRのURLを返却するので、確認してください
